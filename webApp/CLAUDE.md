Core Features

Open-source and lightweight: Safe to use, battery friendly, and easily customizable.

Configurable timer: Adjust length of work and break intervals, long breaks after a set number of sessions.

Pause, skip, or add time: Users can pause, skip sessions, or add 60 seconds as needed.

Structured Pomodoro workflow: Tracks focused sessions and required breaks automatically.

Count-up timer and break budget: Lets users accumulate break time and track flow state.

Labels and profiles: Colored labels with custom time profiles help categorise sessions (premium feature).

Detailed statistics: Built-in productivity statistics and visual data based on labels.

Personalization and Usability
Custom notifications and sounds: Distinct notification sounds for work and break periods, configurable for attention or silence.

Daily reminders and AMOLED-friendly UI: Reminders to start sessions and an interface optimized for battery savings and comfort.

Do Not Disturb mode: Blocks distractions during focus sessions.

Swipe gestures and notification controls: Quick control of timer via gestures; options to display over lock screen or start automatically.

Translations: Available in 42 languages.

Wearable support: Notifies users on smartwatches for hands-free productivity.

Advanced and Premium Features
Backup and export/import: Export statistics as CSV/JSON, backup/restore for data portability.

Manual session editing: Users can manually add or edit sessions and notes.

Theme and dynamic color: Customize the app’s appearance with themes and color schemes.

Configurable start of day/week: Set custom rules for how stat tracking begins.

Screensaver mode: Minimize distractions when in session (premium).
